# go_proxy_mux v1.2.1

This security patch rebuilds the proxy with Go 1.26.10 to include the latest security fixes available in the Go 1.26 branch.

## Changes

- Raise the minimum Go version from 1.26.7 to 1.26.10, updating the standard-library code used for HTTP/2, TLS, and certificate verification.
- Update the Docker builder to `golang:1.26.10-alpine3.24` and pin its multi-platform image digest.

## Upgrade notes

Install the new binary or pull `hightemp/go_proxy_mux:1.2.1` and restart the running proxy to apply the standard-library fixes. Existing proxy configurations remain compatible.

This release updates the Go runtime and standard library. Linux kernel TCP/MPTCP vulnerabilities require separate operating-system updates.

Prebuilt binaries for Linux, macOS, and Windows and the Compose examples are attached with `SHA256SUMS`. Docker images are published for `linux/amd64` and `linux/arm64` as `hightemp/go_proxy_mux:1.2.1` and `hightemp/go_proxy_mux:latest`.
